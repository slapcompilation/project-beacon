Install the Marketplace Bundle
This course requires a specific Marketplace bundle to be installed to provide the necessary data.
If someone else has already installed it on your Foundry instance, you can likely reuse it. Otherwise, you will need to install your own copy.
Having trouble?
If you're having trouble installing Marketplace products, your organization may be controlling which users are able to install Marketplace products or create new resources such as Projects, Objects, Actions, etc. Please check your local Training app or reach out to your platform administrator for help. See the earlier Permissions & Help section for details.
Step 1: Open Marketplace
1. Click on Applications on the left side of the screen

2. Search for Marketplace and open it.
Step 2: Open Deep Dive: Transforming your data with Code Repositories
1. Search for the Deep Dive: Transforming your data with Code Repositories product in the top search bar labeled Search products... (not the lower search bar labeled Search stores...)
2. Click into the corresponding product

Step 3: Start the installation
1. Click Install or Install again in the top right corner
Step 4: Customize the installation
1. Change the installation location to your Code Repo Training folder, specifically the raw folder.

2. You can do this by selecting Use existing location > Browse > Select your raw folder > Save
3. You will then be returned to the General screen where you can then select Next
Step 5: Confirm the content
1. Review the outputs and select Next

2. Ensure that all validations have passed 3. Select Install
Step 6 : Complete the installation
1. Wait for the installation to finish, this shouldn't take longer than a couple of minutes 2. Once installation has completed, select View Installation.
3. You can then navigate to your raw folder to confirm the datasets have been installed
