Mark multiple shipments for consolidation using functions
In the previous part of the course, you used an action type to mark a shipment as eligible for consolidation. This action type was defined using Ontology Manager's pointand-click interface. This point-and-click interface provides a quick and easy way to configure simple actions.
To implement more involved logic in action types--such as looping over a set of objects, conditional functionality, or complex aggregations--you can use Functions. Once you've authored the function, you can can create a function-backed action type. In addition to backing actions, functions can be leveraged directly from a Workshop application to compute object sets or metrics.
Functions in Foundry are written in TypeScript or Python. They provide an expressive framework to interact with and leverage the Ontology.
In this last hands-on part of the course, you will create a function-backed action type that allows marking multiple shipments as eligible for consolidation at the same time.

You'll now modify the code within the index.ts file. The following instructions will walk you through each change with an explanation of what that code change does. If you get stuck, this section ends with the complete contents of the modified file that you can copy all at once.
1. Update the import statements at the top of the file to the lines below:
import { OntologyEditFunction, Edits } from "@foundry/functions-api"; // TODO: Update based on the API for your Shipment object type import { ObjectSet, UsernameShipment } from "@foundry/ontology-api";

OntologyEditFunction is used to decorate a function to indicate that it is a Foundry Function that makes edits to the ontology.

Edits is another decorator used alongside OntologyEditFunction to indicate the specific object types that the function edits The second line imports: The ObjectSet type for interacting with object sets in Functions Your <username> Shipment object type As noted in the TODO comment, you must update the API name to match your personal object type.
2. Replace UsernameShipment with the API object name you confirmed in Step 5.1 above This name is case-sensitive.

4. Add a new markShipmentsForConsolidation function block within your class

Insert this code immediately below the class line that you just edited above. As noted in the copied code, you will need to update your object type name in two places by replacing your username.
// TODO: Update based on the API for your Shipment object type @OntologyEditFunction() @Edits(UsernameShipment) public markShipmentsForConsolidation(shipments: ObjectSet<UsernameShipment>): void {
}
This code contains the function signature: the function's name, return type, parameter names, and parameter types. Specifically:
The function name is markShipmentsForConsolidation The function takes a single input parameter: an object set of Shipments The function has a return type of void (nothing), since it will make changes to the ontology rather than returning a value. Functions used in function-backed action types cannot return anything and so they must have a return type of void . The function must be public so it can be called from other parts of Foundry, e.g. Workshop applications
Above the function signature are the two decorators you imported earlier:
The function needs to be decorated with @OntologyEditFunction() so it is recognized as a function that edits the ontology The function needs to be decorated with @Edit(<Username>Shipment) so it is recognized as a function that edits, specifically, objects of type <Username>Shipment
5. Add two lines of logic to the body of your function
Here is the complete function:

// TODO: Update based on the API for your Shipment object type @OntologyEditFunction() @Edits(UsernameShipment) public markShipmentsForConsolidation(shipments: ObjectSet<UsernameShipment>): void {
const allShipments = shipments.all();
allShipments.map(shipment => shipment.status = "Eligible for Consolidation"); }
The two new lines here:
Materializes the shipments object set that is passed into the function into a list of shipments using the .all() function Iterates over that list of shipments and changes the status property of each one to Eligible for Consolidation
Thus the status of all the shipment objects passed in via the object set will be updated to reflect that each shipment is eligible for consolidation.
Because you can delete the original /* commented out */ code, your full index.ts file now should look like this (except with your Username updated in 3 places):
import { OntologyEditFunction, Edits } from "@foundry/functions-api";
// TODO: Update based on the API for your Shipment object type import { ObjectSet, UsernameShipment } from "@foundry/ontology-api";
export class ShipmentOperationsCenterFunctions {
// TODO: Update based on the API for your Shipment object type @OntologyEditFunction() @Edits(UsernameShipment) public markShipmentsForConsolidation(shipments: ObjectSet<UsernameShipment>): void {
const allShipments = shipments.all();
allShipments.map(shipment => shipment.status = "Eligible for Consolidation"); }
}
If you want to, you can remove the two // TODO lines.
