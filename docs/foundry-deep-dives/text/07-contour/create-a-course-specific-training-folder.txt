Create a Course-Specific Training Folder
Step 1: Create a folder
1. In the top left, click on the star to favorite your project This will allow you to find it quickly later on
2. Click New in the center of the screen or in the top-right corner 3. Select Folder

(Tip: Right-click on the image and click "Open Image in New Tab" to see the full-size version)
4. Name the new folder after the current learning course For example: Deep Dive: Data Analysis with Contour
