Create a Foundry Learning Project
If you already have your own Learning Project on your Foundry instance you can skip this step and move on to the next step to create your course-specific folder.
Step 1: Create a new project
1. Click on Files in the left sidebar 2. Click on Projects in the top bar 3. Click on New project in the top right
Note: If you do not have permissions to create a project, please select a project you feel comfortable using and continue with the next instructions to create a folder.

4. Select your organization's space from the dropdown 5. Select the Default Template 6. Give your project a name, such as: Learning (<username>) 7. Give your project a description that would help another user understand what the project
contains and is used for 8. Do not select a Portfolio, as this is optional 9. In the 'Advanced' dropdown, this typically defaults to granting others the Editor role. To
keep your training uneditable, you can change this to Viewer 10. Click on Create project
