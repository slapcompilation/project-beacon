# Map of the mirror

What is in `docs/foundry-reference/mirror/`, by section and page title.

**This is a floor plan, not a reading.** It answers "does a page about X exist,
and what is it called" — the question that keeps going wrong. `staging` appears
in no URL, but `manage-models/release-model` defines it; link semantics are not
in `search-syntax` even though the word "link" is. Grep titles here first, then
open the page, then write a reading.

Generated by hand-run from the mirrored files. Sections with 0 pages were
requested but returned nothing — worth re-mirroring before concluding Foundry
lacks the concept.

Readings written so far live in `../readings/`. One page in a thousand-page
corpus being read is the normal state early on; the map is how the other 999
stay findable.
