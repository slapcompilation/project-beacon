# Foundry docs — URL index

grouped by capability area. Source: `https://www.palantir.com/docs/sitemap.xml` (fetched 2026-07-23).

- **3696** canonical English Foundry doc URLs across **115** sections.
- The sitemap ships localized (`zh`/`jp`/`kr`) trees; locale prefixes were stripped to the canonical
  English URL, recovering conceptual sections the raw English sitemap slice (capped at 5000) omitted.
