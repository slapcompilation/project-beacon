# Agent basics

An Agent represents an AIP Chatbot (formerly an AIP Agent) created in [AIP Chatbot Studio](/docs/foundry/chatbot-studio/overview/) (formerly AIP Agent Studio).
This API uses the term "Agent" for backwards compatibility.
