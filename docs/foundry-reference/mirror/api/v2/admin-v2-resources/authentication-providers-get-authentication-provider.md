# Get Authentication Provider

`GET /api/v2/admin/enrollments/{enrollmentRid}/authenticationProviders/{authenticationProviderRid}`

:::callout{theme=warning title=Warning}
  This endpoint is in preview and may be modified or removed at any time.
  To use this endpoint, add `preview=true` to the request query parameters.
:::

Get the AuthenticationProvider with the specified rid.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: `api:admin-read`.

Scopes: `api:admin-read`

## Path parameters

- `enrollmentRid` · string · required
- `authenticationProviderRid` · string · required

## Query parameters

- `preview` · boolean
  "Enables the use of preview functionality."

## Response

- `AuthenticationProvider` · object · required
  - `rid` · string · required
  - `name` · string · required
  - `realm` · string · required
    "Identifies which Realm a User or Group is a member of. The `palantir-internal-realm` is used for Users or Groups that are created in Foundry by administrators and not associated with any SSO provider."
  - `enabled` · boolean · required
    "Whether users can log in using this provider."
  - `supportedHosts` · list
    "This provider can only be utilized from these hosts."
    - `HostName` · string · required
  - `supportedUsernamePatterns` · list
    "Users who enter usernames that match these patterns will be redirected to this authentication provider."
  - `protocol` · union · required
    - `saml` · object
      - `serviceProviderMetadata` · object · required
        "Information that describes a Foundry Authentication Provider as a SAML service provider. All information listed here is generated by Foundry."
        - `entityId` · string · required
          "The static SAML entity ID that represents this service provider."
        - `metadataUrl` · string · required
          "A public URL from which this service provider metadata can be downloaded as XML."
        - `acsUrls` · list
          "The Assertion Consumer Service (ACS) URLs for this service provider, to which the SAML identity provider redirects authentication responses."
        - `logoutUrls` · list
          "The URLs for this service provider to which the SAML identity provider sends logout requests."
        - `certificates` · list
          - `CertificateInfo` · object · required
            - `pemCertificate` · string · required
              "The certificate, in PEM format."
            - `commonName` · string
            - `expiryDate` · string · required
            - `usageType` · enum · required
              one of `ENCRYPTION`, `SIGNING`, `UNSPECIFIED`
    - `oidc` · object

## Errors

- `AuthenticationProviderNotFound` (NOT_FOUND) — "The given AuthenticationProvider could not be found."
