# Dataset basics

A Dataset is a representation of data from when it lands in Foundry through when it is mapped
into the Ontology. For more information, refer to the [datasets](/docs/foundry/data-integration/datasets/) user documentation.

Dataset endpoints are not compatible with [restricted views](/docs/foundry/security/restricted-views/) or 
unmaterialized views.
