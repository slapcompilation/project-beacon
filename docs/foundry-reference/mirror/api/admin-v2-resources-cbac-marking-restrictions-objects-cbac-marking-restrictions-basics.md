# Cbac Marking Restrictions basics

Information about whether a set of markings constitutes a valid classification, as defined by the rules in the CBAC asset. The markings and rules about how to combine them are published in documents like [this](https://www.cdse.edu/Portals/124/Documents/jobaids/information/IC-Markings-System-Register.pdf. These restrictions can be used by a dialog for selecting CBAC markings to determine if the markings selected are valid and sufficient for a classification).
