# Create Export Job

`POST /api/v2/notepad/exportJobs/create`

:::callout{theme=warning title=Warning}
  This endpoint is in preview and may be modified or removed at any time.
  To use this endpoint, add `preview=true` to the request query parameters.
:::

Creates a new ExportJob either from an existing Document or using the content generated by a GenerationJob.
If an ExportJob succeeds, it will produce a File that can be downloaded.


Third-party applications using this endpoint via OAuth2 must request the following operation scope: `api:notepad-export`.

Scopes: `api:notepad-export`

## Query parameters

- `preview` · boolean
  "Enables the use of preview functionality."

## Request

- `CreateExportJobRequest` · object · required
  - `exportJobSource` · union · required
    "Defines the source of contents for an ExportJob"
    - `generationJobSource` · object
      - `templateRid` · string · required
        "The unique identifier for a Template"
      - `generationJobRid` · string · required
        "Used to export contents from a GenerationJob that has successfully completed"
    - `documentSource` · object
      - `documentRid` · string · required
        "Used to export contents from a Document"
  - `exportJobTarget` · union · required
    "The target format that the job will export to."
    - `pdf` · object
      - `userLocale` · string · required
        "The locale to use for formatting in the export."
      - `userTimezone` · string · required
        "The timezone to use for formatting dates and times in the export. Only IANA timezones are accepted (a two part timezone ID in the form of Area/Location, e.g. 'America/New_York')."

## Response

- `ExportJob` · object · required
  - `rid` · string · required
    "The unique identifier for an ExportJob"
  - `status` · union · required
    "The status of an export job"
    - `running` · object
      "The export job is currently running"
    - `failed` · object
      "The export job failed"
      - `errorMessage` · string · required
        "The error message explaining why the export failed"
      - `errorCode` · string
      - `errorInstanceId` · string
    - `succeeded` · object
      "The export job succeeded"
      - `fileRid` · string · required
        "The File containing the exported content"

## Errors

- `GenerationJobStatusFailed` (FAILED_PRECONDITION) — "The operation cannot be completed because the generation job has failed status."
- `GenerationJobStatusRunning` (FAILED_PRECONDITION) — "The operation cannot be completed because the generation job has running status."
- `DocumentNotFound` (NOT_FOUND) — "The requested document was not found."
- `ExportDocumentPermissionDenied` (PERMISSION_DENIED) — "The user does not have export permissions on this Document."
- `ExportGenerationJobPermissionDenied` (PERMISSION_DENIED) — "The user does not have export permissions on this GenerationJob."
- `InvalidExportJobUserLocale` (INVALID_ARGUMENT) — "The provided user locale is not valid."
- `InvalidTimezone` (INVALID_ARGUMENT) — "The provided timezone is not valid."
- `CreateExportJobPermissionDenied` (PERMISSION_DENIED) — "Could not create the ExportJob."
- `GenerationJobNotFound` (NOT_FOUND) — "The given GenerationJob could not be found."
