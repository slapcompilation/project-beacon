# Numeric cards

Back to: [Index of cards](/docs/foundry/quiver/cards-index/)

Cards in this section return and display numbers.

The following cards accept object sets and return a single number:

* [Numeric aggregation](/docs/foundry/quiver/card-numeric-aggregation/)

The following cards accept single objects and return a single number:

* [Object property](/docs/foundry/quiver/card-object-property/)
