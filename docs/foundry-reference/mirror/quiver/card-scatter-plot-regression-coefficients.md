# Scatter plot regression coefficients

Derive the regression equation coefficients from a [scatter regression plot](/docs/foundry/quiver/card-scatter-plot-regression/), and output the coefficients as an array.

## Input type

Time series scatter plot regression

## Output type

Number array

## Usage information

| Functionality | Availability |
| --- | --- |
| [Standard Quiver card](/docs/foundry/quiver/core-concepts/#cards) | Supported |
| [Transform table transform](/docs/foundry/quiver/cards-transform-table/) | Unsupported |
