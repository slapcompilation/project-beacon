# Date to string

Convert a date into a string. Optionally provide a format for how the date should be displayed, such as `YY-MMM-DD`.

## Input type

Date

## Output type

String

## Usage information

| Functionality | Availability |
| --- | --- |

| [Transform table transform](/docs/foundry/quiver/cards-transform-table/) | Supported |
