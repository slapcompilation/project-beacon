# String cards

Back to: [Index of cards](/docs/foundry/quiver/cards-index/)

Cards in this section return and display strings.

The following cards accept object sets and return strings:

* [Unique property values](/docs/foundry/quiver/card-unique-property-values/)
* [Property value select parameter](/docs/foundry/quiver/card-property-value-select-parameter/)

The following cards accept single objects and return a string:

* [Object property](/docs/foundry/quiver/card-object-property/)

The following cards accept transform tables and return strings:

* [Transform table column values](/docs/foundry/quiver/card-transform-table-column-values/)

The following cards accept other strings and return strings:

* [Substring](/docs/foundry/quiver/card-substring/)

* [To upper case](/docs/foundry/quiver/card-to-upper-case/)
* [Multipass attribute](/docs/foundry/quiver/card-multipass-attribute/)

The following cards accept time series and return a single string:
