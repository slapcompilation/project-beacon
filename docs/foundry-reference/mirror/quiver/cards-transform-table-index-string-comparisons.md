# String comparisons

Back to: [Index of transforms](/docs/foundry/quiver/cards-transform-table-index/)

Transforms in this section compare [string data types](/docs/foundry/quiver/analysis-data-model/).
These comparison transforms are useful for filtering transform table rows by string columns. These comparison transforms can also be used separately outside of transform tables.
