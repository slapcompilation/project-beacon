# Object property

Takes an object as input and returns a property value. Supported property types are numeric, time, and string.

## Input type

Single object

## Output type

String, number, time

## Usage information

| Functionality | Availability |
| --- | --- |
| [Standard Quiver card](/docs/foundry/quiver/core-concepts/#cards) | Supported |
| [Transform table transform](/docs/foundry/quiver/cards-transform-table/) | Unsupported |
