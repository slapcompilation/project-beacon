# Index of transform table transformations

Below is the full index of transforms that can be used in a [transform table](/docs/foundry/quiver/cards-transform-table/).  Transforms are categorized by the *transform action type*, such as editing columns, filter data, joining data, operating and comparing values, or null/error handling.

You can browse transforms by category or simply search for a transform using free text. Learn more about [how to search for and add a transformation](/docs/foundry/quiver/cards-transform-table/#add-a-transformation).
