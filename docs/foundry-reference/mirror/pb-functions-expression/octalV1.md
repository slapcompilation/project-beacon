# Convert to octal

> Supported in: Batch, Faster, Streaming

Computes octal value of given expression.

**Expression categories:** Numeric

## Declared arguments

* **Expression:** Input column.<br>*Expression\<Integer | Long | Short>*

**Output type:** *String*
