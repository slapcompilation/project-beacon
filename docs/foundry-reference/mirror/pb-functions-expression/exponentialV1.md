# Exponential

> Supported in: Batch, Faster, Streaming

Calculates the exponential, e^x, of a column.

**Expression categories:** Numeric

## Declared arguments

* **Expression:** Exponent value.<br>*Expression\<Numeric>*

**Output type:** *Double*

## Examples

### Example 1: Base case

**Argument values:**

* **Expression:** 2.0

**Output:** 7.38905609893

***

### Example 2: Null case

**Argument values:**

* **Expression:** *null*

**Output:** *null*
