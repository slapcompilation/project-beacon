# Negate

> Supported in: Batch, Faster, Streaming

**Expression categories:** Numeric

## Declared arguments

* **Expression:** Expression to be negated.<br>*Expression\<Numeric>*

**Output type:** *Numeric*

## Examples

### Example 1: Base case

**Description:** Negating decimal

**Argument values:**

* **Expression:** 10.0

**Output:** -10.0
