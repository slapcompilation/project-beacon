# Add sync or export to a Marketplace product

Use [Foundry DevOps](/docs/foundry/devops/overview/) to include your Data Connection syncs and exports in [Marketplace products](/docs/foundry/devops/core-concepts/#product) for other users to install and reuse. [Learn how to create your first product.](/docs/foundry/foundry-devops/create-products/)

## Supported features

Both standard [syncs](/docs/foundry/data-connection/set-up-sync/) and [streaming syncs](/docs/foundry/data-connection/set-up-streaming-sync/) can be included in Marketplace products. Additionally, Data Connection [exports](/docs/foundry/data-connection/export-overview/) can be packaged alongside syncs in Marketplace products.

## Adding Data Connection syncs and exports to products

To add a Data Connection sync or export to a product, first [create a product](/docs/foundry/foundry-devops/create-products/). Select **Add output**, then select a Data Connection source. The dialog will walk you through the process and allow you to include both syncs and exports in your Marketplace product.
