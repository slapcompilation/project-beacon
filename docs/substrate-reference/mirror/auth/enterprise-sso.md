# Enterprise Single Sign-On

Learn about Single Sign-On support in Supabase Auth for enterprise applications

Supabase Auth supports building enterprise applications that require Single Sign-On (SSO) authentication [with SAML 2.0](https://supabase.com/docs/guides/auth/enterprise-sso/auth-sso-saml).
